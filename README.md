# سیستم آموزشی ریاضیات جلال

برنامهٔ وب به زبان دری برای شاگردان صنف‌های ۷ تا ۱۲، با طراحی راست‌چین و فونت سادهٔ Arial.

## اجرای آنلاین
سایت با GitHub Pages نشر می‌شود: https://schoolfarhikhta123-star.github.io/jalal-math-system/

## امکانات افزوده‌شده
- نقشهٔ موضوعات پنج شاخه برای صنف‌های ۷ تا ۱۲
- درسنامه‌های نخست صنف هفتم با تعریف، تشریح و مثال حل‌شده
- ساخت کاربرگ ۳۰ پرسشی از تمرین‌های مرتبط با هر درس صنف هفتم
- چاپ کاربرگ در قالب A4 با جای پاسخ
- بازی ده‌پرسشی با گزینه‌ها، بازخورد تشریحی و ذخیرهٔ امتیاز در همان مرورگر
- پوستهٔ برنامه برای دسترسی آفلاین پس از بارگذاری نخستین بار
- طراحی مناسب موبایل و دسکتاپ

## نکته دربارهٔ محتوا
نقشهٔ موضوعات صنف‌های دیگر در برنامه دیده می‌شود، اما درسنامهٔ کامل همهٔ صنف‌ها هنوز نوشته نشده است. فایل ویدیوی واقعی نیز هنوز اضافه نشده؛ بخش ویدیو این موضوع را روشن می‌گوید. نسخهٔ آفلاین فعلی فایل‌های برنامه را نگه می‌دارد و شامل ویدیو نیست.

## نشر تغییرات
فایل‌ها در شاخهٔ `main` قرار دارند و GitHub Pages پس از پایان ساخت، نسخهٔ تازه را منتشر می‌کند. اگر نسخهٔ قبلی دیده شد، صفحه را با `Ctrl + F5` تازه‌سازی کنید.
