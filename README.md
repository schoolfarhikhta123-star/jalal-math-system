# سیستم آموزشی ریاضیات جلال

برنامهٔ وب به زبان دری برای صنف‌های ۷ تا ۱۲، با طراحی راست‌چین و پیشرفت ذخیره‌شده در مرورگر.

## مرحلهٔ فعلی: حساب صنف هفتم
چهار درس این شاخه آماده شده‌اند:
1. اعداد صحیح و عملیات
2. کسرها و اعداد اعشاری
3. نسبت و تناسب
4. درصد و کاربرد آن

هر درس شامل تعریف، توضیح، مثال‌های حل‌شده، کاربرگ امتحانی ۳۰ پرسشی، پاسخ‌نامهٔ جداشدنی و چهار حالت بازی است: تمرینی، زمان‌دار، زنجیرهٔ پاسخ درست و آزمون امتیازی. هر بازی ۳۰ پرسش دارد و امتیاز در همان مرورگر ذخیره می‌شود. کاربرگ با طراحی رنگی و قاب امتحانی برای چاپ A4 آماده شده است؛ برای حفظ رنگ‌ها در چاپ، گزینهٔ چاپ رنگی مرورگر را فعال کنید.

## محدودیت‌ها
این مرحله فقط محتوای حساب صنف هفتم را تکمیل می‌کند. شاخه‌ها و صنف‌های دیگر هنوز تکمیل نشده‌اند. اطلاعات شاگرد و امتیازها محلی‌اند و میان دستگاه‌ها همگام نمی‌شوند. ویدیوهای واقعی در این نسخه وجود ندارند.
