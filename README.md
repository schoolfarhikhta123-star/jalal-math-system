# سیستم آموزشی ریاضیات جلال

این پروژه، یک برنامهٔ آموزشی وبی برای شاگردان صنف‌های 7 تا 12 است که روی موبایل و کمپیوتر قابل استفاده است. 

## ویژگی‌های اصلی
- درس‌ها و شاخه‌های ریاضی: حساب، الجبر، هندسه، مثلثات، ریاضیات عالی
- ظاهر فانتزی و رنگارنگ، مناسب برای نوجوانان
- تعریف، توضیح، مثال‌ها، کاربرگ، ویدیو و بازی آموزشی
- کاربرگ‌های ۳۰ سوالی برای چاپ و پرنت
- سازگار با زبان دری و اصطلاحات ساده
- ساختار مناسب برای نسخه‌های بعدی با ویدیوهای آفلاین واقعى

## اجرای پروژه
برای اجرای پروژه، فایل `index.html` را در مرورگر باز کنید. 

اگر بخواهید نسخهٔ کامل‌تر و قوی‌تر آن را بسازید، می‌توانید در آینده:
- فایل‌های ویدیوی آفلاین اضافه کنید
- صفحات جداگانه برای هر درس بسازید
- سیستم لاگین و ثبت نام برای شاگردان اضافه کنید
- نمره‌دهی و پیگیری پیشرفت اضافه کنید
