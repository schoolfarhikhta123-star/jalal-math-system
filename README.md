# حساب صنف هفتم

مرحلهٔ حساب صنف هفتم تکمیل شد: اعداد صحیح و عملیات، کسرها و اعشار، نسبت و تناسب، و درصد و کاربرد آن.

هر درس شامل:
- تعریف و توضیح کامل
- مثال‌های حل‌شده
- کاربرگ امتحانی رنگی A4 با ۳۰ سوال
- پاسخ‌نامه و راه‌حل‌ها
- چهار بازی ۳۰‌سؤالی: تمرینی، زمان‌دار، زنجیره‌ای و آزمون امتیازی
- ذخیرهٔ امتیاز و پیشرفت در مرورگر

سایر شاخه‌ها و صنف‌ها در مراحل بعدی تکمیل می‌شوند.
