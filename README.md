# سیستم آموزشی ریاضیات جلال

برنامهٔ وب به زبان دری برای صنف‌های ۷ تا ۱۲، با طراحی راست‌چین، فونت Arial و پشتیبانی پایه از استفادهٔ آفلاین.

## نسخهٔ فعلی شامل
- پروفایل محلی شاگرد (نام و صنف)؛ اطلاعات فقط در مرورگر همان دستگاه ذخیره می‌شود و حساب آنلاین/رمز عبور ندارد.
- نقشهٔ پیشنهادی موضوعات پنج شاخه برای صنف‌های ۷ تا ۱۲.
- درسنامهٔ صنف هفتم در پنج شاخه، با تعریف، تشریح و مثال حل‌شده.
- برای هر درس موجود: کاربرگ ۳۰ پرسشی، چاپ A4، بازی ۱۰ پرسشی با بازخورد و امتیازدهی، و ثبت تکمیل درس.
- ذخیرهٔ امتیاز و پیشرفت در مرورگر و پوستهٔ برنامه برای دسترسی آفلاین پس از بازدید آنلاین نخست.

## محدودیت‌های محتوایی
نقشهٔ صنف‌های ۷ تا ۱۲ به معنی تکمیل همهٔ درس‌ها نیست. در این نسخه فقط یک درس نمونه برای هر شاخهٔ صنف هفتم آماده است؛ عنوان‌های دیگر هنوز درسنامه و تمرین کامل ندارند. ویدیوی واقعی نیز افزوده نشده است. پیشرفت محلی است و میان دستگاه‌ها همگام نمی‌شود.
